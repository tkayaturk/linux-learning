# Day 01 - Command Structure

Today I learned the basic structure of command-line commands.

## Command

A command tells the terminal what to execute.

Example:

```bash
cheese
```

## Options

Options change how a command is executed.

Example:

```bash
cheese -x
```

- `cheese` = command
- `-x` = option

## Arguments

Arguments are values passed to a command.

Example:

```bash
makebaby John Sarah
```

- `makebaby` = command
- `John` = argument
- `Sarah` = argument

## Multiple Options

Short options can be written separately:

```bash
ls -S -r
```

or combined:

```bash
ls -Sr
```

## Case Sensitivity

Uppercase and lowercase options are different.

```text
-r is not the same as -R
-S is not the same as -s
```
