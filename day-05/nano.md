# Day 5 - Nano Text Editor

## What I practiced

- Opening and editing files with `nano`
- Saving changes and exiting Nano
- Using Nano shortcuts instead of manually editing large files

## Useful shortcuts

- `Ctrl + O` - write/save the file
- `Ctrl + X` - exit Nano
- `Ctrl + G` - open Nano help
- `Ctrl + \` - search and replace text
- `Ctrl + _` - go directly to a line/column
- `Ctrl + R` - read another file and insert its contents at the cursor
